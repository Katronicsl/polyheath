# PolyHealth

Веб-приложение для образовательных целей на тему здоровья и ЗОЖ. Проект включает информационные статьи, набор тестов для самооценки и личный кабинет пользователя с сохранением результатов.

## Функционал

- **Аутентификация** — регистрация и вход пользователей
- **Статьи** — информационные материалы по темам:
  - Гигиена сна
  - Управление стрессом
  - Отказ от курения
- **Тесты** — интерактивные тесты для оценки:
  - Качества сна
  - Уровня стресса
  - Степени никотиновой зависимости (тест Фагерстрема)
- **Профиль пользователя** — сохранение избранных статей и результатов тестов
- **Поиск** — навигация по статьям и тестам с фильтром по названию

## Стек технологий

- **Backend**: Python (Flask)
- **Database**: PostgreSQL
- **Frontend**: HTML, Jinja2
- **Auth**: Flask-Login
- **ORM**: SQLAlchemy

## Установка и запуск

### Требования
- Python 3.8+
- PostgreSQL
- pip

### Шаги

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Katronicsl/polyheath.git
cd polyheath
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте базу данных:
   - Создайте БД PostgreSQL с именем `site`
   - Убедитесь, что учётные данные в `app.py` совпадают с вашей конфигурацией:
   ```python
   app.config['SQLALCHEMY_DATABASE_URI'] = "postgresql+psycopg2://postgres:postgres@localhost:5432/site"
   ```

4. Запустите приложение:
```bash
python app.py
```

Приложение будет доступно на `http://localhost:5000`

## Основные маршруты

| Маршрут | Описание |
|---------|---------|
| `/` | Главная страница |
| `/profile` | Профиль пользователя (требует авторизации) |
| `/navigatortests` | Каталог тестов |
| `/navigatorarticle` | Каталог статей |
| `/test/<test_type>/<question_id>` | Прохождение теста |
| `/article/<article_slug>` | Чтение статьи |
| `/info` | Информационная страница |

## Модели данных

### User
- `id` — уникальный идентификатор
- `username` — имя пользователя (уникальное)
- `password` — хеш пароля

### Favorite
- `id` — уникальный идентификатор
- `user_id` — ID пользователя
- `article` — название избранной статьи

### TestResult
- `id` — уникальный идентификатор
- `user_id` — ID пользователя
- `test_name` — название теста
- `percent` — процент правильных ответов
- `result` — итоговая оценка/интерпретация

## Примечания

- Приложение использует простую аутентификацию; для продакшена нужна улучшенная безопасность
- Текущий `SECRET_KEY` указан в коде; для продакшена использовать переменные окружения
- Разработано в рамках учебного проекта 2-го курса колледжа
